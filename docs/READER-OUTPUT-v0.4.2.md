# v0.4.2：发表正文与本地溯源分离

微信正文和已批准 Markdown 导出不再自动插入内部 Claim 编号、来源脚注或“参考来源”附录。正文中由作者主动写入的公开链接、引用与说明继续保留。

本地 Artifact 原文、Claim、Evidence、Material、Review 及批准版本不变。对外输出只是移除注册的内部 Claim 标记；用户仍可在 Vault 中核查所有来源和审查依据。已有旧版导出文件及其回执保留，新导出使用 reader-v2 文件名与 approved-markdown.v2 协议。

已投递记录仍按当时保存的 payload 核验，不用新版渲染规则改写历史事实。尚未发送的旧预览因正文不符会被拒绝，需要取消并重新准备。

当前账号的既有草稿已按用户本轮指示更新同一 media_id：先回读确认与旧回执一致，保存旧快照，再更新正文并回读。核验状态 REMOTE_DRAFT，未调用公开发表接口。本轮实际回执位于私有运行目录，不进入安装包。后续若要编辑任意已有草稿，仍需专门的产品编辑流程；本轮没有新增通用草稿编辑 UI。

验证：新增对外隐藏内部溯源、本地证据不变、保留作者公开链接及 HTML 转义的回归；完整结果见 verification.json。微信后台视觉排版及实际 Obsidian 宿主交互没有在本轮重新验证。
