## 修复及观察

- 公众号回执按远端真实状态分开处理；publish_id 只受理，成功需状态与文章内容核验。
- 网络期间本地文章变化时保留远端回执，但不把当前未批准版本标记为已发表。
- 发现并修复多稿项目在另一稿已拒绝后被错误提升状态的风险，新增回归测试。
- UI 测试切换到模拟服务时曾遗留一个空闲的隔离 Kernel。通过完整命令行、父进程及运行任务为空确认归属后停止该唯一进程，恢复正常服务；没有停止个人 Vault 的服务。最终正常重启已复验。

## 可用边界与剩余工作

本版可以安装、管理材料、运行原编辑流程、预览并通过官方协议投递、管理回执与经验。尚未证明特定真实账号的权限、微信对 HTML 的具体转换行为或实际排版效果。严格回读可能出现保守冲突，不能因此放宽批准版本门禁。

单篇图文、保守 20 KB 正文、JPEG/PNG 封面上传；暂不自动上传正文图片、不提供完整模板排版、不抓取微信统计、不定时发表、不群发、不自动修改已发表原链接。API 缺乏条件写入，最终读取与发表间的远端编辑窗口无法完全排除；结果未知且所有 ID 丢失时仍需人工找回。详见 `WECHAT-SETUP.md`。
