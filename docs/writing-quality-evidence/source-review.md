# GitHub 写作技能来源选择

选择依据是完整指令、示例、许可与本项目适配性，不以 star 数判断写作质量。以下“采用”只指有限原则的中文适配，不执行上游的工具调用或工作流。

## 采用

   - https://github.com/alchaincyf/huashu-report/tree/bdc08bee5077462e1300431408c5237438a22d00
   - MIT，Copyright 2026 alchaincyf
   - 重点读了 SKILL.md、references/研究深度.md、references/行文.md
   - 优点：把整理资料与解释机制区分开；检查比较口径、分析层次、竞争解释和结论边界
   - 限制：上游面向研究报告，明确排除单篇文章；只取可迁移编辑原则，不导入整套报告模板/视觉生产。教程中的数字和引用未被当作已验证用户证据

   - 固定版本：f4518a8eab97b8bfebc66a89d34320a89bef6930
   - https://github.com/op7418/Humanizer-zh/tree/f4518a8eab97b8bfebc66a89d34320a89bef6930
   - MIT，Copyright 2026 歸藏
   - 完整阅读主技能、示例与许可
   - 优点：优先保护独立信息、否定、比较、归因、条件和完成状态；允许保持作者声音，不把词表当黑名单
   - 限制：适合编辑既有文字，不替代研究、构思或证据核实；不能保证“通过 AI 检测”

## 未采用

- ComposioHQ/awesome-claude-skills 的 content-research-writer：完整技能有协作提纲/研究优点，但示例补入原文没有的个人经历、数字与引文；本次检查未确立根目录再分发许可
- guzhezao/writer-skill：偏特定作者声音和营销风格，未确认清晰再分发许可；不作为完整读过的四个候选之一
- obra/the-elements-of-style：英文经典原则不是中文证据推理层的替代品；原始1918文本的公版说明不等于现代包装文件都可随意再分发

这份选择报告说明来源取舍，不证明写作质量提高。受控同题样稿结果另见集成说明；软件测试只验证提示注入、协议与资源完整性。
